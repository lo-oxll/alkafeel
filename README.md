# العتبة العباسية المقدسة — صفحة الروابط

صفحة روابط ثابتة (HTML/CSS/JS) بدون أي مكتبات خارجية. تعمل على GitHub Pages مباشرة.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة والأيقونات (SVG داخلية) |
| `style.css` | التصميم والوضع الليلي/النهاري |
| `app.js` | التاريخ الهجري، المناسبات، النسخ/المشاركة/QR |
| `occasions.js` | قائمة المناسبات الدينية (يمكن تعديلها) |
| `qrcode.js` | مولّد QR (MIT) |
| `logo-day.jpg` / `logo-night.jpg` | شعار النهار / الليل |
| `og-image.jpg` | صورة المعاينة عند مشاركة الرابط |

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع كل الملفات إلى الجذر.
2. Settings ← Pages ← Deploy from a branch ← `main` / `(root)`.

## بعد النشر: رابط المعاينة (مهم)
افتح `index.html` وغيّر الرابط في الأسطر `og:url` و`og:image` إلى رابط موقعك، مثل:
`https://USERNAME.github.io/REPO/` و`https://USERNAME.github.io/REPO/og-image.jpg`

## تحديث التاريخ الهجري كل شهر
في أول `app.js` أضف سطراً إلى `MONTH_STARTS` عند ثبوت هلال الشهر الجديد:
```js
['2026-12-12', 1448, 7],   // غرة رجب — [تاريخ الغرة الميلادي، السنة الهجرية، رقم الشهر]
```
ما لم يُسجَّل يُحسب تقريبياً. التاريخ الهجري يتغيّر عند المغرب (بتوقيت بغداد)؛
لتغييره عند منتصف الليل اجعل `CHANGE_AT_MAGHRIB = false`.
